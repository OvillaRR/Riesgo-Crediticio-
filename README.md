 Applied ML: Notes & Theoretical Framework (v1.0)
 
 Este repositorio es una base de conocimiento técnica dedicada al estudio, análisis y aplicación de modelos de Machine Learning. Este proyecto prioriza la rigurosidad teórica, 
 explicando los fundamentos matemáticos y conceptuales detrás de cada arquitectura.📖 Estructura Académica del ContenidoEl material está organizado siguiendo un flujo de aprendizaje lógico, desde la estadística descriptiva hasta los modelos 
 avanzados de Deep Learning:
 I. Fundamentos (Secciones 1-5)Calidad de Datos: Análisis de completitud, precisión y normalización.Análisis Exploratorio 
 (EDA): Detección de outliers mediante Local Outlier Factor y técnicas de transformación.II. 
 Modelado Supervisado y No Supervisado (Secciones 6-7)Modelos Supervisados: Estudio comparativo entre métodos lineales y no lineales:Regresión Lineal, Random Forest, LDA y QDA.
 Aprendizaje No Supervisado:Reducción de Dimensionalidad (PCA, Multidimensional Scaling).Algoritmos de Clustering (K-Means, DBSCAN).III. Deep Learning (Sección 8)Teoría de Redes: Funciones de activación, propagación hacia adelante y 
 el proceso de Backpropagation como optimización de gradiente.$\mathcal{L} = -\sum \log P(y|x)$Regularización: Estrategias para evitar el sobreajuste (Early Stopping, Dropout).🏛 Metodología de DocumentaciónEste
 proyecto sigue un enfoque de "Teoría primero, código después". Cada módulo incluye:Fundamentos Matemáticos: Descripción de las ecuaciones clave.Análisis de Aplicación: Discusión sobre por qué un modelo es preferible sobre otro
 bajo condiciones específicas.Demos: Implementaciones de referencia para validar la teoría expuesta.
